## 2. 逐集流程

### 第 1 集（演示）
- 展示成品：参数改一改，机翼跟着变；
- 出现 **法则曲线** 对话框（知识工程 → 法则）；
- 末尾展示材质/物理属性面板（密度、热膨胀等），说明模型可进一步用于分析；
- 字幕："电子版本的开口这里前缘尖端会略有差异的，实际前缘后掠角要在精度范围内"。

### 第 2 集（建模过程，核心）

1. **建参数**：从 Excel/记事本**一次性复制整列**粘贴进 CATIA 参数表
   （字幕："复制的数据需要一次性粘贴"、"这里使用 ALT+ENTER 快捷键"）。
2. **画轮廓草图**：在草图里画俯视梯形（根弦、梢弦、展向、后掠），
   **用约束**（平行.1/平行.2/相合.3/相合.4…、宽度/角度尺寸）把形状锁死，
   再把尺寸用**公式**接到参数上 → 改参数形状自动变。
   出现的关键公式：`实现过程\草图.1\宽度.1\角度`、`比率 = 0.5*翼根弦长/100mm`。
3. **翼型库**：把多条翼型（NACA0008、NACA2418…）作为曲线放进"翼型库"几何体；
   `翼型选择器`（字符串参数）配合规则/选择决定用哪条。
4. **缩放**：把单位翼型缩放到实际弦长（第 6 集更正：用**缩放/投影**，不要复制草图）。
5. **引导线**：从前缘/后缘生成直线（直线.1/直线.2/直线.3）。
6. **扫掠**（画面读到对话框）：
   - 轮廓类型：**显式**
   - 子类型：**使用两条引导曲线**
   - 轮廓：`草图.4`；引导曲线 1/2：两条引导线；**定位类型：两个点**
   - 脊线：默认（引导曲线）
   - 角度修正 0.5deg、与引导线偏差 0.00mm、自交区域偏移 2%、连接方式：自动
7. **扭转**：`平移.1` 的角度 = **`10deg*几何扭转`** 公式 —— 扭转不是靠扫掠的角度法则，
   而是**先旋转轮廓/后旋转结果**的独立特征。
8. **对称 + 接合**：`对称` 得到全翼，`接合.1` 缝合成一张面。
9. **测量**：`测量曲面.1` 量出半翼面积，展弦比公式 = `b² / 区域 / 2`。

### 第 3 集（翼肋，顺气流布置）
- 用 **矩形阵列** 生成一系列**顺气流平面**：参数"实例和间距"，例子 **2 个 / 20mm**，
  参考方向未选；
- 平面与翼面 **相交** 得到每个翼肋的截面轮廓（画面里可见 3 条绿色切片面）；
- 字幕："找到扫掠机翼时的两条引导曲线"（回顾引导线）；
- 结论：**翼肋 = 等间距平面阵列 ∩ 翼面**，不是手画。

### 第 4 集（翼尖）
- 翼尖做**圆角/过渡**，参数越小曲率半径越小、连接处曲率变化越大；
- 字幕："对于开口造型需要通过填充曲面封闭"（端盖）；
- 末尾用 **斑马线分析** 检查曲面光顺（重要：他也在做质量检查）。

### 第 5 集（BWB 插曲）
- 把同一套参数化思路套到翼身融合体上（2 分钟，思路演示）。

### 第 6 集（更正一）
- 字幕："回到 4 分 22 秒处的开头操作，**这里不先开始创建草图，而是先进行缩放**"；
- 字幕："**投影到结构中的缩放**，而不是视频中的复制"。
- 含义：翼型不要靠复制几何，应该用**缩放 + 投影**保持关联。

## 3. 十个关键技术点（可直接借鉴）

1. **参数从表格批量粘贴**，别一个个敲（ALT+ENTER 快速进入公式）。
2. **参数化靠草图约束 + 公式**，不是靠脚本算坐标。
3. **翼型库常驻多条翼型**，用字符串参数 + 规则切换，而不是重新导入。
4. **翼型缩放用"缩放/投影"**，保证改弦长时曲线跟着走（第 6 集更正）。
5. **扫掠 = 显式 + 两条引导曲线 + 两个定位点 + 默认脊线**（画面读数）。
6. **扭转用独立的旋转/平移特征**，角度写成公式（`10deg*几何扭转`）——
   这条路比扫掠的"角度法则"更可靠（我们在 pycatia 里试过角度法则，
   挂 reference 就 update 失败，他这个做法能解释我们为什么失败）。
7. **对称 + 接合**：先对称出全翼，再缝合成一张曲面。
8. **展弦比用测量面积定义**：`b²/(面积×2)`。注意这与理论梯形面积差约 **2.8%**（见下）。
9. **翼肋 = 等间距平面阵列 ∩ 翼面**，改间距就自动重切。
10. **翼尖要圆角 + 填充封闭 + 斑马线检查**；开口造型必须封口才能做实体/网格。

## 4. 参数体系核对（用画面数值反算）

第 2 集某状态：`翼根弦长=50mm，翼展展长=600mm，梢根比=0.45，翼型 NACA2418`
- 他的展弦比显示 **17.020133073**
- 反算测量面积：`600²/(2×17.0201) = 10,575 mm²`
- 梯形半翼理论面积：`(50+22.5)/2 × 300 = 10,875 mm²`
- **差 −2.8%**

另一状态（第 3 集）：`翼根弦长=200mm，翼展展长=800mm，λ=0.45`，展弦比 **5.6739019**
- 测量面积 = `800²/(2×5.6739) = 56,398 mm²`；理论 = `(200+90)/2×400 = 58,000 mm²`
- **差 −2.8%**

结论：他的 `测量曲面.1` 系统性偏小约 2.8%（可能量的是曲面而非投影，或翼尖/前缘有修形）。
所以**他的展弦比 ≠ 理论展弦比**，约高 2.8%。
> 我们的做法：用解析式 `AR = 2b/(c_root(1+λ))`，与理论一致，且不依赖测量特征。
> 两者差异要记录在案——如果你要跟他的数值对齐，就改用测量式。

## 5. 与我们实现的对照

| 环节 | 他的做法 | 我们的实现 | 取舍 |
|---|---|---|---|
| 参数 | 手工粘贴 + 公式 | 脚本建参数 + 反引号公式 | 等价，脚本更快 |
| 平面形状 | 草图 + 约束 + 公式 | Python 算坐标（或扫掠引导线端点公式） | 他的更"CAD 原生"（改参数即动）；我们的更可控 |
| 翼型缩放 | 缩放 + 投影 | `add_new_hybrid_scaling` + 比率公式 | 一致 ✔ |
| 扫掠 | 显式 / 双引导 / 两点定位 / 默认脊线 | 同（已实测通过） | 一致 ✔ |
| **扭转** | **独立旋转特征 + 角度公式** | 多截面曲面里把扭转算进截面坐标 | 他的更易改参；我们的几何更精确 |
| 展弦比 | 测量面积式（偏 2.8%） | 解析式 | 建议保留解析式 |
| 翼肋 | 平面阵列 ∩ 翼面 | **尚未实现** | ← 本次要补 |
| 翼尖 | 圆角 + 填充 + 斑马线 | 未做 | 后续 |
| 曲面检查 | 斑马线 | 未做（建议人工） | 后续 |

## 6. 本次据此对程序做的修改

见 `wing_builder.py` / `launcher.py` 的更新说明（同目录 `机翼参数化建模_可行性分析.md` §11）。

1. 新增 `--ribs`：**翼肋生成**（等间距平面阵列 ∩ 翼面），参数为间距与起止；

4. 启动器增加对应选项与提示。

## 7. 不确定 / 待核

   推测 `几何扭转` 实际是**无量纲数**（1.0 表示 10deg），或公式里是 `10deg*几何扭转` 的显示简化。
   **需要在源 .CATPart 里确认。**
2. 第 3 集阵列的"实例和间距"截图为 `2 / 20mm`，但画面上有 3 条切片线，可能中途改过参数。
3. `测量曲面.1` 到底量的是哪张面（半翼曲面 / 投影面），仅凭画面无法确定。
