## 0. 需求对齐（对着你截图里的设计树）

你要的不是"把翼型曲线画进 CATIA"，而是**用脚本长出一棵能自己联动更新的参数化设计树**：

```
参数
 ├ 翼型选择器   = NACA0018        (String)
 ├ 翼根弦长     = 100mm           (Length)
 ├ 翼展展长     = 500mm           (Length)
 ├ 后掠角       = 30deg           (Angle)
 ├ 几何扭转     = 10deg           (Angle)
 ├ 梢根比       = 0.45            (Real)
 ├ 展弦比       = b²/S/2 (公式)   (Real，由公式算)
 └ 安装角       = 10deg           (Angle)
关系
 ├ 展弦比公式（引用参数与"实现过程"里的测量）
 └ 翼型选择规则（按 翼型选择器 激活对应翼型）
翼型库        ← 几何图形集：各翼型曲线/草图，可被引用
实现过程      ← 几何图形集：引导线、法则、基准、测量
机翼
 ├ 扫掠        ← 翼型沿引导线扫出，俯视形状由参数决定
 └ 对称
零件几何体
测量
```

**关键词是"俯视图的形状由参数拉伸出来"**——也就是后掠角 + 弦长 + 梢根比决定翼平面形状，用扫掠做出；几何扭转用角度法则叠加；翼型由翼型库取出。

**结论先说：这条路线可行，而且能做成"改了参数 CATIA 自己更新"，不需要每次重跑脚本。** 依据见第 2、3 节。

## 3. 五个关键接口事实（写代码必须知道，都是踩出来的）

### 3.1 ★ 公式必须用**反引号**，不是单引号/双引号

```python
body = "`翼展展长`*`翼展展长`/(`翼根弦长`*`翼展展长`*(1+`梢根比`)/2)"
part.relations.create_formula("展弦比公式", "", ar_param, body)
```

实测四种写法：

| 写法 | 结果 |
|---|---|
| `翼展展长*翼展展长/...`（裸名） | ❌ 公式体为空，值 = 0 |
| `='翼展展长'*...`（带等号） | ❌ 值 = 0 |
| `'翼展展长'*'翼展展长'/...`（单引号） | ❌ 值 = 0 |
| ``  `翼展展长`*`翼展展长`/...  ``（反引号） | ✅ **值正确，且改参数自动重算** |

CATIA 会自动把名字补成全名：`` `Part2\翼根弦长` ``。所以**不要在表达式里自己拼 Part 前缀**。

### 3.2 ★ 几何点的坐标本身就是参数，可以挂公式

这是"脚本建树也能真参数化"的关键：

```python
pt = hsf.add_new_point_coord(10, 20, 0)
pt.x        # -> Length 参数，名为 "测试点\X"，值 10mm
part.relations.create_formula("X公式", "", pt.x, "`翼根弦长`/2")
# 改 翼根弦长 = 200 → pt.x 自动变成 100mm ✅ 实测
```

**含义：引导线的端点点位可以挂公式引用参数 → 改了后掠角/弦长，俯视形状由 CATIA 自己重算，脚本不用重跑。**

### 3.3 扫掠能做梢根比，但靠"双引导线"，不是"缩放法则"

`HybridShapeSweepExplicit` 只有 `angle_law`（角度法则），**没有缩放法则**。所以：

- **几何扭转** → 用 `angle_law`（✅ 实测通过）
- **梢根比/后掠** → 用**两条引导线**：前缘引导线（后掠）+ 后缘引导线（弦长收缩），翼型剖面在两线之间过渡（✅ 实测通过）

顺带：`add_new_hybrid_scaling` 存在，可以把翼型整体缩放到弦长——比给每条曲线的每个点挂公式更省事。

### 3.4 可选参数占位要用 `vba_nothing`

```python
from pycatia.scripts.vba import vba_nothing
loft.add_section_to_loft(ref, 1, vba_nothing)   # 传 None 会 AttributeError
```

### 3.5 几何不合法时，`add_*` 静默成功，`update()` 才报错

```
pywintypes.com_error: (-2147352567, '发生意外。', (0, 'CATIAPart', '方法 Update 失败', ...))
```

CATIA 不告诉你哪个特征坏了。实现时必须：每个特征命名 → 分步 update → 失败时定位并回滚 → 参数快照写日志。

## 4. 三个硬缺口与对策

### 4.1 ⚠️ 规则（Rule）写不进去 —— 翼型自动切换受影响

- 现象：`create_rule_base` 能建对象（COM 类名 `CATIAExpertRuleBaseRuntime`），但 `modify(body)` 一律失败；`RuleSet` 只读。
- 已排除许可问题：`create_check`（同样属于 Knowledge Advisor）通过。
- 这是 pycatia / 该 CATIA 版本的接口缺口，不是语法问题。

**对策（按推荐度）：**

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 一次性手工规则** | 脚本建树时把 `翼型选择器` 参数和所有翼型曲线建好，**"切换规则"由你在 CATIA 里手工点一次**（或在你现有模板里已有），之后改参数自动切换 | 需要一次人工，之后全自动 |
| **B. 脚本决定翼型** | 脚本读入你输入的翼型名，直接只建那一条（或建全部但只把选中的接进扫掠） | 换翼型要重跑脚本（几秒） |
| **C. 设计表 / 暂停更新** | 用 `create_design_table` 或"活动/停用"手工配置 | 复杂度高 |

**注意：你现有模板（那张图）里已经有这个规则了**——如果走"模板 + 脚本填参数"的混合路线，这一项直接绕过。

### 4.2 ⚠️ "展弦比 = b²/测量曲面区域/2" 这个公式的隐患

你截图里展弦比引用的是 `测量曲面.1\区域`。反算一下：`500²/(2×7.092477) ≈ 17624 mm²`，而梯形半翼理论面积是 `100×250×1.45/2 = 18125 mm²`，差了约 2.8%。

可能的原因（得看你的模型确认）：
- 测量的不是**翼平面投影面积**，而是曲面面积（曲面面积 > 投影面积，且随扭转/厚度变化）；
- 或者翼尖有修形/圆角。

**建议**：展弦比用**解析式**更稳，不依赖测量特征：

```
展弦比 = b² / S ，其中 S = c_root · b · (1+λ) / 2
⇒ 展弦比 = `翼展展长`*`翼展展长`/(`翼根弦长`*`翼展展长`*(1+`梢根比`)/2)
```

实测该式算出 6.8965517，与理论一致。好处：改参数即时联动、不依赖几何是否更新、也不怕测量特征丢失。**这条公式人家已经验证可用了。**

（如果你的 测量曲面 是有意为之——比如想用真实湿面积定义展弦比——那说明一下，人家按你的口径来。）

### 4.3 ⚠️ 后掠角口径与"集合扭转"

- **后掠角**至少三种口径：前缘后掠 `Λ_LE`、1/4 弦线后掠 `Λ_c4`、后缘后掠 `Λ_TE`。三者数值差别很大，必须先定口径，否则"参数对、俯视形状错"，而且肉眼看不出来。
- **"集合扭转"**人家理解为**几何扭转**（沿展向的 washout/washin）——即每个截面的安装角随展向变化，由 `几何扭转` 参数 + 角度法则实现。若你指的是别的（如沿弦向的扭转分布），需要修正模型。

## 5. 推荐架构：脚本建全树 + 关键尺寸挂公式

```
① 脚本读取输入（命令行交互 / JSON / Excel）
        ↓
② 建参数：翼根弦长(L) 翼展展长(L) 后掠角(A) 几何扭转(A) 梢根比(R) 安装角(A) 翼型选择器(S)
        ↓
③ 建公式：展弦比 = b²/S ；引导线端点坐标 = f(后掠角, 弦长, 梢根比)
        ↓  ← 这一步是关键：挂上公式后，CATIA 自己联动
④ 建 翼型库：按输入翼型生成闭合样条（可留多条备用），按弦长缩放
        ↓
⑤ 建 实现过程：前缘引导线 + 后缘引导线 + 扭转法则
        ↓
⑥ 建 机翼：扫掠(翼型, 双引导线, 角度法则) + 对称
        ↓
⑦ update → 保存 .CATPart
```

**产出效果：**

- 第一次运行 → 得到你要的设计树（结构与你截图一致）；
- 之后在 CATIA 里改 `翼根弦长 / 翼展展长 / 后掠角 / 梢根比 / 几何扭转 / 安装角` → **俯视形状和扭转自动更新**（因为关键点位挂了公式），不需要再跑 Python；
- 换翼型 → 要么重跑脚本（秒级），要么用模板里已有的规则。

**与"模板 + 脚本"路线的对比：**

| | 脚本建全树 | 模板 + 脚本填参数 |
|---|---|---|
| 首次搭建 | 全自动，无手工 | 需要你现有的 .CATPart |
| 翼型切换 | 需重跑 / 手工规则 | 模板里已有规则，直接可用 |
| 稳健性 | 依赖脚本无 bug | 高（几何逻辑已在 CAD 里验证过） |
| 适合 | 从零、批量化、参数扫描 | 快速上手、贴近你现有工作流 |

### 9.2 ★ 新发现：脊线是必需品

不建脊线时，扫掠会把截面**顺着斜引导线带歪**——面积恰好少 `cos(后掠角)`：

| 配置 | 扫掠面积 | 判定 |
|---|---|---|
| 无脊线（后掠 30°） | 0.031971 m² | ❌ 少 13.7% ≈ cos30° |
| 脊线＝前缘线 | 0.031971 m² | ❌ 同样被带歪 |
| **脊线＝沿展向 Y 直线** | **0.038107 m²** | ✅ 与解析值一致 |

所以 `实现过程` 里必须有一根沿展向的直线做脊线，并在扫掠上 `sweep.spine = 脊线`。
这一条对方的教程里也会体现（否则机翼会是"斜切的板"）。

### 9.3 ✅ 已按方案 A 重构：多截面曲面（真实截面 + 几何扭转）

因为下游要跑仿真，几何必须站得住，所以主建模方式改为 `--method loft`：

- 沿展向布置 **N 个真实截面**（默认 7 个），每个截面独立计算：弦长线性收缩、
  1/4 弦线后掠、安装角 + 几何扭转（`θ(y) = 安装角 + 几何扭转·y/(b/2)`），
  绕展向轴旋转后平移到对应站位；
- 用 **多截面曲面** 串联，再做 **对称**；
- `--method sweep` 保留作对照（该方案无法驱动扭转，原因见下）。

实测（NACA0018；c_root=100 mm，b=500 mm，Λ¼=30°，λ=0.45，安装角 10°，扭转 10°，7 截面）：

| 项 | 实测 | 理论 | 偏差 |
|---|---|---|---|
| 截面 1 周长（y=0） | 208.10 mm | 207.6 mm | +0.2% |
| 截面 7 周长（y=250） | 93.64 mm | 93.4 mm | +0.3% |
| 多截面曲面面积 | **0.038400 m²** | 0.037625 m² | +2.1% |
| 截面扭转角 | 10.00° → 20.00° 线性 | 10° → 20° | 0 |
| 对称件 | 面积/周长一致 | — | 0 |

几何可信，可以直接进入下游（加厚、布尔、网格划分）。

#### 附：扫掠方案的扭转为什么放弃（记录在案）

| 做法 | 结果 |
|---|---|
| 仅 `sweep.angle_law = 法则` | 静默无效（面积分毫不变，最容易骗人） |
| `sweep.reference = 平面` + `angle_law` | `update()` 抛 COMError |
| `reference` 取 xy / zx / yz | 均失败 |

官方文档写明 `AngleLaw` 是"关联到参考曲面的"，而平坦基准面与该版本扫掠求解器不兼容。
另外扫掠还要求一根**沿展向的脊线**，否则截面会被斜引导线带歪（面积少 `cos(后掠角)`，30° 时少 13.4%）。

### 9.4 🖥 启动器（GUI）

`launcher.py`：**导入翼型 .dat → 填参数 → 一键生成设计树**。

- 翼型库：多选导入 `.dat`（自动识别 Tab / 空格 / 逗号），显示点数与最大厚度比；

- 输出：可指定 `.CATPart` 保存路径；
- 操作：⚡ 生成（后台线程，不卡界面）/ 仅计算校验 / 截图；
- 日志：`wing_builder` 的全部输出实时打到界面。


### 9.5 单位坑（测量时注意）

CATIA 的 `Measurable.Area` 返回 **m²**，而 `Length` 返回 **mm**。
混着看会得出"面积才 0.03"这种误判。

### 11.1 新增：翼肋（对齐第 3 集"等间距平面阵列 ∩ 翼面"）

`powershell
python wing_builder.py --config cfg.json --ribs --rib-spacing 40
# 或 JSON: "ribs": true, "rib_spacing": 40
`

做法：以 XZ 平面为基准，按间距生成偏置平面（实现过程\翼肋平面_NN），
与机翼曲面**相交**得到顺气流截面（几何图形集\翼肋\翼肋_NN），再镜像到另一侧。

实测（NACA0018，c_root=100，b=500，Λ¼=30°，λ=0.45，7 截面，间距 40）：
- 6 个翼肋 + 6 个镜像，全部 update 通过；
- 翼肋_01（y=40）周长 **189.8 mm**，该站弦长 90.83 → 理论周长 ≈ 188.6（+0.6%）；
- 翼肋_02（y=80）周长 **171.5 mm**，该站弦长 81.67 → 理论 ≈ 169.5（+1.2%）。

**踩坑记录（重要）**：dd_new_plane_offset(plane_zx, y, orientation) 的
orientation=False 才指向 +Y（机翼侧）；True 会把平面偏到另一侧，
相交为空 → part.update() 抛 COMError，且**不告诉你是哪个特征**。
代码里已加"双向重试 + 失败改名废弃"的处理。

### 11.2 新增：展弦比双口径

`powershell
python wing_builder.py --ar-mode analytic   # 默认：解析式，与理论一致、随参数联动
python wing_builder.py --ar-mode measured   # 对齐 UP 主：建模后按实测翼面面积回填
`

- nalytic：` 翼展展长*翼展展长/(2*(翼根弦长+梢根比*翼根弦长)/2*翼展展长/2) `
  → 实测 6.896551724（理论 6.896552）。
- measured：建模完用 SPA 测量翼面面积 → 半翼面积 → AR = b²/S_half，
  与理论值对照打印偏差。**注意这是回填静态值，不随参数联动**（CATIA 的
  测量特征在 pycatia 里不易做成活的参数，UP 主是在 GUI 里手工挂的）。
