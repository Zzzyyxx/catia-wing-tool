# 环境安装指南（换一台电脑时看这份）

本项目要在**你自己的电脑**上运行 CATIA 的 COM 自动化，所以需要三样东西：

1. **Windows**（COM + tkinter 界面都是 Windows 生态）
2. **CATIA V5**（已正常安装、能正常启动）
3. **Python 3.11 + pycatia**（本文件讲怎么装）

> 关键点先说：**Python 必须是 3.11**（3.12 部分可用，3.13/3.14 目前装不上 `pywin32` 轮子）；
> **Python 位数必须和 CATIA 一致**——64 位 CATIA 就用 64 位 Python。

---

## 路线 A：用 Anaconda / Miniconda（推荐）

适合没装过 Python、或想多环境隔离的情况。

### A1. 装 Miniconda（没装过 Anaconda 的话）

1. 下载 <https://docs.conda.io/en/latest/miniconda.html>（Windows 64-bit）
2. 安装时勾选 **"Add Miniconda3 to my PATH"**（可选，勾了后面命令行能直接用 `conda`）
3. 装完打开 **Anaconda Prompt**（开始菜单里）

### A2. 建环境 + 装依赖（两条命令）

```bat
conda create -n catia311 python=3.11 -y
conda activate catia311
python -m pip install pycatia
```

`pycatia` 会自动带上 `pywin32`。装完验证：

```bat
python -c "import pycatia; import win32com; print('OK')"
```

### A3. 告诉启动器用哪个 Python

`启动器.bat` 会按这个顺序找解释器：

1. 环境变量 **`CATIA_PY`**
2. `%USERPROFILE%\anaconda3\envs\catia311\python.exe`（Anaconda 默认位置）
3. `%ProgramData%\anaconda3\envs\catia311\python.exe`
4. PATH 上的 `python`

如果你装在别处（比如 `D:\Miniconda3\envs\catia311`），设一下环境变量就行：

```powershell
setx CATIA_PY "D:\Miniconda3\envs\catia311\python.exe"
```

（设完要**重开终端**才生效。）

---

## 路线 B：官方 Python + venv（不想装 Anaconda）

### B1. 装 Python 3.11

1. 下载 <https://www.python.org/downloads/release/python-3119/> → **Windows installer (64-bit)**
2. 安装时**务必勾选 "Add python.exe to PATH"**
3. 验证：

```bat
python --version
:: 应输出 Python 3.11.x
```

### B2. 建虚拟环境（推荐，别装进全局）

```bat
cd /d D:\CATIA_Wing_Tool
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install pycatia
```

### B3. 让启动器用这个环境

```powershell
setx CATIA_PY "D:\CATIA_Wing_Tool\.venv\Scripts\python.exe"
```

## 路线 C：一键脚本（本仓库自带）

如果你已经有 conda，直接双击：

```
工具\安装环境.bat
```

它会自动：建 `catia311` 环境 → 装 pycatia（用清华镜像加速）→ 跑一遍环境自检。
中途需要网络，大约 1~3 分钟。

---

## 装完怎么验证

双击 **`工具\环境检查.bat`**，它依次检查：

1. 找到的 Python 版本（必须是 3.11）
2. `import pycatia` 是否成功
3. 连接 CATIA（`CATIA.Application`）是否成功
4. 建 Part、建点、建多截面曲面、知识工程参数是否可用

全部通过 = 环境就绪。**第一次连接会冷启动 CATIA，约 15 秒，别以为卡住了。**

## 常见错误对照

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'pycatia'` | 装到了别的 Python 上 | 用 `"%CATIA_PY%" -m pip install pycatia` 明确指定解释器 |
| `pip install pywin32` 编译失败 | Python 是 3.13/3.14，没有对应轮子 | 换 Python **3.11** |
| `pywintypes.com_error: 无效的类字符串` | CATIA 没装 / COM 未注册 / 位数不匹配 | 确认 CATIA 能启动；64 位 CATIA 配 64 位 Python |
| `pywintypes.com_error: 服务器运行失败` | CATIA 进程卡死，或上一次被强杀 | 任务管理器结束 `CNEXT.exe` 后重试 |
| 生成时报 `方法 Update 失败` | 几何不合法（不是环境问题） | 看弹窗里的「阶段」+ 日志 `logs\build_*.log` |
| `方法 SaveAs 失败` | 保存路径含中文/特殊字符 | 换英文路径（工具也有临时文件中转兜底） |
| pip 下载极慢 | 默认源太远 | 加镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 启动器闪退 / 弹「环境不对」 | 双击用的是系统自带的旧 Python | 用 `启动器.bat`，或设 `CATIA_PY` |
| `Bad magic number in .pyc file` | 多个 Python 版本混用 | 删掉目录里的 `__pycache__`；用 `启动器.bat` |

## CATIA 侧的检查

自动化依赖 CATIA 的 COM 注册（ProgID：`CATIA.Application`）。查一下：

```powershell
Get-ItemProperty "Registry::HKEY_CLASSES_ROOT\CATIA.Application\CLSID" | Select-Object '(default)'
```

- 有输出（一长串 `{...}` 的 GUID）→ 注册正常；
- 报错"找不到路径" → CATIA 没装好，或装的是不提供 V5 自动化的版本。

另外：**CATIA 不需要提前打开**，脚本会通过 COM 拉起；但第一次冷启动较慢，
如果公司环境限制了 COM 启动（或用远程桌面会话），建议手动先开 CATIA 再跑脚本。

## 卸载 / 清理

```bat
:: 只删环境
conda env remove -n catia311

:: 或删 venv 目录
rmdir /s /q D:\CATIA_Wing_Tool\.venv

:: 取消 CATIA_PY 环境变量
setx CATIA_PY ""
```

本工具不会往系统里写任何东西（除了你设的 `CATIA_PY` 和生成的 `logs\`、`output\`）。
